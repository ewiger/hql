# `Decimal`

In [`std/core`](../index.md).

```hql
type Decimal : {Scalar, Orderable}
```

An exact decimal number, written with a decimal point and no suffix
(`2.50`), ordered by value: `0.1 + 0.2 == 0.3` is `true`. See
[Decimal](../../../../learn/02-data-types/decimal.md).
