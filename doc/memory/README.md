# Memory

`doc/memory/` holds **small real-time decisions** that have not yet found a home
in the knowledge base. It is a staging area, not an archive.

A note belongs here only while it is undigested. Once the decision is stated in
the place that owns it — a [wiki card](../wiki/README.md), a
[model document](../models/), [`doc/stack.md`](../stack.md) — the note is
deleted rather than kept as a record of how the decision was reached.

**The current state is the source of truth.** Cards and models say what is true
now, not what used to be true and was replaced. Where a former state matters as
an audit trail, it belongs in [`doc/status/`](../status/), which exists for
exactly that and is not rewritten.

A decision too large for a note belongs in [`doc/proposals/`](../proposals/) as a
numbered specification; work to carry one out belongs in
[`doc/issues/`](../issues/).
